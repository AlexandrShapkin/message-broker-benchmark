# Metrics

Define every collected metric here before using it in final research results.

At minimum document:

- requested, offered, accepted and delivered throughput;
- publish latency;
- end-to-end delivery latency;
- p50/p95/p99/p99.9;
- CPU;
- RSS;
- network RX/TX;
- disk I/O;
- logical clients;
- actual connections;
- errors, lost messages, duplicates and disconnects.
