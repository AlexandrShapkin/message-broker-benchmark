# Methodology

This document defines the scientific methodology of the benchmark.

Before the first real experiment, specify:

- research questions;
- independent variables;
- dependent variables;
- controlled variables;
- warm-up and measurement phases;
- repetitions;
- open-loop workload semantics;
- coordinated-omission handling;
- generator saturation rules;
- run validity criteria;
- statistical aggregation;
- comparison limitations.
