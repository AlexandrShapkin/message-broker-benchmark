# ADR-0005: Архивная baseline srv0 и влияние заполнения диска

Status: Accepted

## Контекст

Архив srv0 содержит smoke, synthetic, exploratory, финальные, failed и
незавершённые попытки. Девять failed-запусков финальной серии RabbitMQ содержат
ошибки ENOSPC. Пять completed-запусков имеют явный `disk resource limit alarm set`
в запечатанном broker log. Завершение runner не гарантирует пригодность
для причинного сравнения ёмкости. Часть proc streams ранее обратимо сжата Zstandard.

## Решение

Сохранить все файлы, статусы и пустые каталоги попыток; опубликовать неизменённые
raw файлы в версии GitHub Release с файловыми SHA-256, размером и инвентарём.
Сжатые proc streams распаковывать только во временной копии и проверять по
исходному artifact hash манифеста. Генерировать CSV/JSON/Parquet через существующий
валидатор, без новых измерений и изменения raw contract.

В основной cohort входят строго валидированные `nir1_final_*` completed runs
без зарегистрированного disk resource alarm. Наличие такой строки в broker log
на любом этапе консервативно исключает run из основной сравнительной агрегации;
факт, исходный результат и все показатели остаются в `observed-final-runs` и
реестре. Это правило относится к архивной baseline, а не меняет runner или
общую трактовку delivery failures. Потери сами по себе не скрываются и не
становятся автоматической причиной исключения. Failed/incomplete и auxiliary
сохраняются отдельно с объяснением.

Использовать строгий ключ повторений ADR-0004. Не объединять гарантии профилей,
среды, workload или процентили потока. Показывать индивидуальные повторы и
min–max, без заявлений о превосходстве по bootstrap CI при малом n.

Очистить только доказанно benchmark-specific ресурсы srv0 после проверки
удалённого commit, скачивания Release assets и проверки их контрольных сумм
и полного опубликованного инвентаря. Общие зависимости и ресурсы неопределённой
принадлежности сохранять.

## Последствия

Baseline неполная по семействам и брокерам. Ошибки RabbitMQ при нехватке диска
не являются оценкой его максимальной плотности. Для их интерпретации нужны новые
контролируемые измерения, которые этой задачей не запускались. Число валидных
основных запусков меньше числа completed-манифестов; обе величины публикуются.
