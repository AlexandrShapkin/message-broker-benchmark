# Architecture Decision Records

Use ADRs for decisions that affect architecture, experiment semantics,
reproducibility or compatibility.

File naming:

    NNNN-short-title.md

Example:

    0001-go-python-split.md

Template:

# ADR-NNNN: Title

## Status

Proposed | Accepted | Superseded | Rejected

## Context

What problem requires a decision?

## Decision

What has been decided?

## Alternatives considered

What realistic alternatives were evaluated?

## Consequences

Positive and negative consequences.

## Research impact

Does this affect:

- experimental semantics;
- comparability;
- measurement accuracy;
- reproducibility;
- previously collected results?

## Compatibility

Does the change require:

- scenario schema version change;
- manifest version change;
- raw-data schema change;
- rerunning previous experiments?
