# Независимость от прежней локальной копии

Сохранение выполнено перед планируемым удалением checkout с ThinkPad.
Сам checkout этой задачей не удаляется.

## Что сохранено удалённо

- В Git: весь текущий код, пять ключевых графиков в корневом README,
  полный русский отчёт, 35 пар PNG/SVG, компактные таблицы и журналы очистки srv0.
- [Основной Release baseline-srv0-20261109-v1](https://github.com/AlexandrShapkin/message-broker-benchmark/releases/tag/baseline-srv0-20261109-v1):
  все source artifacts измерений srv0, образы брокеров, подробные metadata и timelines.
- [Дополнительный Release local-retirement-v1](https://github.com/AlexandrShapkin/message-broker-benchmark/releases/tag/local-retirement-v1):
  оригинальный полный снимок srv0 и локальная acceptance-история с обоими source bundles.

Локальная история: **3943 файла, 344516722 байта**, 120 completed и 10 failed
итоговых манифестов. Это инфраструктурные проверки и синтетика сентября 2026 года,
не дополнительная научная baseline. Её нельзя агрегировать с основной серией srv0.

Полный снимок сервера сохраняет все 14453 обычных файла, а также исходные symlinks
и пустые каталоги. Он дополняет компактный dataset ранее исключёнными зависимостями,
бинарниками и Git metadata, чтобы оригинальные байты не оставались только локально.

## Проверки

[Восстановление из чистого clone](cold-restore-verification.json) выполнено
в отдельном каталоге после клонирования **с GitHub**, без копирования `.git`
или результатов из рабочего checkout. Архив истории скачан из Release;
все 3943 файла сверены с inventory и восстановлены. Оба bundle прошли
`git bundle verify`; рабочее дерево clone осталось чистым.

[Git-объекты bundle](bundle-object-review.json) проверены отдельно: 146 и 144
объекта, совпадений проверяемых secret patterns нет. Полный снимок srv0 ранее
сверен с серверным inventory и исходными файлами. Дополнительно проверены
Git config (обычный публичный remote без credential URL/auth headers) и
[две отметки сканера в зависимостях](snapshot-font-review.json): Ruff и Pillow
совпадают с установленными пакетами, отметка Pillow находится во встроенном
литерале данных шрифта длиной 17125 байт.

SSH keys, AWS credentials, agent credential stores и домашние конфигурации
пользователя не копировались. Сканирование patterns не заменяет сохранение
этих личных данных в собственном защищённом хранилище.

Проверка скачивания частей полного снимка и опубликованных asset digests
фиксируется в `remote-verification.json` рядом с этим документом.

## Что остаётся только локально и почему это не требуется

Временные распаковки, повторные скачивания и сборочные кэши — производные либо
побайтные дубликаты сохранённых архивов. `.venv`, локальный `bin/`, Python/Go caches,
индексы Serena и package-install logs пересоздаются из кода и locks и не являются
источниками измерений. Игнорируемые `audit.json` и `timeline.*` основной baseline
уже находятся в `analysis-tables-v1.tar.gz`. Все локальные `results/`,
`analysis/output/` и `analysis/smoke-output/` включены в дополнительный архив.
Непубликованных веток текущего checkout нет; дополнительные исторические commits
сохранены в bundle. Личные mount/config directories инструментов не являются
частью архива проекта и не нужны для его воспроизведения.

[Пошаговое восстановление](../../docs/restore.md) не использует абсолютные пути
ThinkPad и не требует действующего benchmark server.
